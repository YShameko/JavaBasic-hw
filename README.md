**HW 16.1. Практика Maven та юніт-тестування**

1. Створити порожній проект в IntelliJ
2. Написати простий калькулятор. Він має вміти додавати, віднімати, ділити та множити 2 числа.
3. Написати юніт-тести до кожної з операцій калькулятора.
4. Виконати команду mvn clean install, після цього в локальному репозиторії (.m2) повинен з'явитись ваш калькулятор.
5. Переконатися, що ваш калькулятор був розміщений у локальному репозиторії.
6. Тепер спробуємо підключити ваш калькулятор у іншому (новому) проекті і використати.
7. Створити порожній проект в IntelliJ
8. Відкриваємо pom.xml і в блоці додавання залежностей (dependencies) підключаємо наш калькулятор.
9. Створюємо клас з main методом, пробуємо використати наш калькулятор і виконати всі операції, які підтримує ваш калькулятор.
