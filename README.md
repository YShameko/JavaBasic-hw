**HW 11.1. Робота з класами та об’єктами***

Створіть Java програму з використанням класів та конструкторів, яка виконує наступні завдання:

1. Створіть клас Person, який представляє особу з такими характеристиками: ім'я, вік та професія. Оголосіть поля для цих характеристик та створіть конструктор класу, який дозволяє встановити значення цих полів при створенні об'єкта класу Person.
2. Створіть об'єкти класу Person для трьох різних осіб, використовуючи конструктор класу Person. Виведіть інформацію про цих осіб на екран.
3. Додайте метод в клас Person, який дозволяє встановити нову професію для особи. Використайте цей метод для зміни професії одного з об'єктів Person, а потім виведіть оновлену інформацію про цю особу на екран.

Приклад:
1. Ім'я: John, Вік: 30, Професія: Інженер

   Ім'я: Mary, Вік: 25, Професія: Вчитель

   Ім'я: Bob, Вік: 35, Професія: Лікар


2. Ім'я: Alice, Вік: 28, Професія: Архітектор

   (Після оновлення професії)

   Ім'я: Alice, Вік: 28, Професія: Дизайнер
